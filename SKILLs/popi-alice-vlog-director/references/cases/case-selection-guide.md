# Alice Vlog Case 选型指南

## 用途

- 这个文件用于在导演阶段先识别用户需要的叙事结构，再从 case 库里只选择 1 个主参考 case。
- 这 3 个 case 都是结构案例，不是具体内容参考。
- case 只提供：
  - 镜头颗粒度
  - 时长分布
  - 段落推进方式
  - prompt 密度和写法
- case 不提供：
  - 具体剧情
  - 具体场景
  - 具体食物、道具、活动
  - 可直接复用的字幕、旁白或事件
- 除非用户明确要求混搭，不要同时混用多个 case。

## 当前 case 库

### 1. `full-day-vlog-case.md`

- 结构定位：线性的一天，从早到晚完整推进。
- 适合借用：
  - 标准日程推进
  - 明确的时间分段
  - 早晨到夜晚的闭环叙事
- 典型气质：完整、稳定、清晰地走完一天。

### 2. `weekend-home-vlog-case.md`

- 结构定位：慢节奏、停留感更强的居家叙事。
- 适合借用：
  - 更松弛的段落节奏
  - 更长的停留镜头
  - 较少地点切换的室内生活流
- 典型气质：柔软、慢、安静、留白更多。

### 3. `new-year-vlog-case.md`

- 结构定位：事件密集、节奏更热闹的节日/活动 montage。
- 适合借用：
  - 多事件串联
  - 群像或家庭互动段落
  - 逐步升温到高潮收尾的结构
- 典型气质：热闹、聚会感强、仪式感明显。

## 结构识别规则

### 先看用户要的叙事形态

- 若用户要的是“从早到晚完整走一遍”，优先选 `full-day-vlog-case.md`。
- 若用户要的是“慢慢过、停留感强、室内生活流”，优先选 `weekend-home-vlog-case.md`。
- 若用户要的是“多事件串联、热闹、多人互动、节庆高潮”，优先选 `new-year-vlog-case.md`。

### 再看节奏和密度

- 若用户只给了一个单片段，不按具体内容关键词选，而按镜头节奏和段落密度选。
- 例如：
  - 一个安静片段需要长停留、慢呼吸，用 `weekend-home-vlog-case.md` 的结构感。
  - 一个完整白天流程需要清晰切段，用 `full-day-vlog-case.md` 的结构感。
  - 一个节庆 montage 需要多事件快速推进，用 `new-year-vlog-case.md` 的结构感。

### 最后看默认归类

- 没有明显活动高潮，且更像陪伴式生活流，默认选 `weekend-home-vlog-case.md`。
- 没有明显活动高潮，但有完整日程推进需求，默认选 `full-day-vlog-case.md`。

## 使用要求

- 先说明自己选了哪个 case 作为主参考，但只用一句话简述结构原因，不要长篇解释。
- 只继承被选 case 的：
  - 镜头颗粒度
  - 段落节奏
  - 提示词密度
  - 生活细节组织方式
- 禁止继承 case 里的具体场景、道具、食物、节日动作、人物关系或字幕文案。
- 具体内容必须从当前用户输入重新生长，不能把 case 当成内容库。
- 若用户后续改题，允许重新选 case，但同一轮里仍然只保留 1 个主参考 case。

## 选型示例

- `想做一条从早到晚完整闭环的一天` -> `full-day-vlog-case.md`
- `想做一条慢节奏、室内停留感强的生活流` -> `weekend-home-vlog-case.md`
- `想做一条多事件串联、越到后面越热闹的节庆片子` -> `new-year-vlog-case.md`
