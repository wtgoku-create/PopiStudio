# Alice 场景连续性参考库

这份参考库专门用于 Alice 的固定生活空间与周边环境连续性控制。

适用范围：

- `image2image`
- `image2video`
- 需要保持 Alice 家、楼下、小区、常去商圈、超市、健身房等场景稳定时

使用原则：

- 这批图不是角色参考，不替代固定 Alice 角色图。
- 若用户指定了场景类别，优先只从对应分类中选参考图，不跨分类混用。
- 若同一期内容包含连续镜头，优先复用同一分类中的相邻参考图，保持空间关系稳定。
- 需要重点保持一致的不是“单张图构图”，而是空间属性：户型关系、家具布局、主色调、窗户方向、采光逻辑、生活痕迹和常见物件位置。
- 若用户只说“室内”或“家里”，先从 `客厅`、`餐厨`、`卧室`、`室内` 中选择最接近当前动作的一组参考。
- 当前先做基础归档，不预设每类的唯一主参考；后续可手动补充“主参考 / 辅参考”标记。
